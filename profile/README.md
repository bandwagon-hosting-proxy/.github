## 二、准备工作：工具和基本认知

在动手之前，有几件事要先弄清楚，否则后面很容易走弯路。

### 什么叫"被墙"？

"被墙"的本质是：你的 VPS IP 地址被国内网络层面列入了屏蔽名单。这种屏蔽发生在网络层，搬瓦工官方并没有主动封禁你的服务器，你的 KiwiVM 后台显示服务器运行正常，只是来自国内的流量被运营商侧直接阻断了。

所以，搬瓦工被墙和"服务器宕机"是两件完全不同的事情。

### 被墙的常见触发原因

使用 VPS 做了某些超出正常范围的操作（比如跑流量异常大的应用、端口行为特征明显等），IP 就容易进入封锁名单。普通建站、跑脚本、学 Linux 这类操作通常不会触发被封。

### 你需要准备什么

- 能访问搬瓦工 KiwiVM 控制面板的账号（如果 IP 已经被封，可以通过镜像站 `bwh81.net` 访问）
- 一台非国内网络的手机或电脑（用于排查）
- 大概 8-9 美元的预算（如果需要付费换 IP）

## 三、第一步：确认 IP 是否真的被封

很多人遇到连不上就慌，其实连不上的原因有好几种：VPS 流量跑完被暂停、服务崩溃、非正常关机、SSH 配置改坏了……被封只是其中一种可能。所以第一步是确认。

### 方法 A：使用搬瓦工官方 IP 检测工具

这是最权威的方式。

1. 登录搬瓦工账号，进入对应 VPS 的 **KiwiVM 控制面板**
2. 在浏览器地址栏打开：`https://kiwivm.64clouds.com/main-exec.php?mode=blacklistcheck`
3. 点击 **Test Main IP** 开始检测

结果有两种：
- **IP NOT BLOCKED** —— IP 没被封，问题在别处（看看 VPS 是否正在运行、流量是否超限）
- **IP BLOCKED** —— IP 确认被封，继续下面的步骤

### 方法 B：用第三方工具交叉验证

可以同时用 [ipcheck.ing](https://ipcheck.ing) 这类工具，输入你的 VPS IP，分别测试国内和国外的连通性。

常见的结果模式：
- **国内 ICMP 通、TCP 不通，国外两者都通** → 端口/TCP 被封（部分封锁）
- **国内 ICMP 和 TCP 都不通，国外都通** → IP 完全被封
- **国内国外都不通** → 服务器本身有问题，跟被墙无关

这一步判断很关键，因为"端口被封"和"IP 完全被封"的解决方式是不一样的。

## 四、第二步：判断封锁类型

### 情况 A：IP 完全被封（ICMP + TCP 均不通）

这是最常见的情况。整个 IP 被拉黑，任何协议的请求都被丢弃。需要更换 IP 才能解决。

### 情况 B：只有特定端口被封（ICMP 通但 TCP 不通）

这种情况下，IP 本身还没被彻底封，只是某个端口的行为特征被识别并阻断了。可以尝试更换端口后再试。

在 KiwiVM 后台，有些套餐支持一键更换 SSH 端口，或者你可以直接用 Emergency Console（紧急控制台，不走 SSH，在 KiwiVM 面板里找）登录进去改端口配置。

## 八、常见错误与排查

**Q：官方检测工具显示 IP NOT BLOCKED，但还是连不上？**

先重启 VPS（在 KiwiVM 控制面板里点击 Restart），再检查流量是否已超限（月流量跑完会被暂停服务）。还不行，检查 SSH 配置是否被改动过。

**Q：换了新 IP，但几天后又被封了？**

说明当前的使用方式本身有触发风险。建议换线路（换到 SLA 套餐），同时检查 VPS 上运行的应用流量特征是否过于明显。
